# Smart-Street-Light-Arduino

## Project Overview
This project demonstrates a Smart Street Light System using Arduino Uno, PIR Sensor, and LDR Sensor.

The system automatically:
- Turns OFF during daytime
- Operates at DIM brightness during nighttime
- Switches to FULL brightness when motion is detected

This helps reduce power consumption and improves energy efficiency.

## Features
- Automatic Day/Night Detection
- Motion Detection using PIR Sensor
- PWM Brightness Control
- Energy Efficient Street Lighting
- Arduino-based Automation

## Components Used
- Arduino Uno
- PIR Sensor (HC-SR501)
- LDR Sensor
- LED
- 220Ω Resistor
- 10kΩ Resistor
- Breadboard
- Jumper Wires

## Working Principle
- LDR detects ambient light intensity.
- During daytime, LED remains OFF.
- At night:
  - If motion detected → LED glows at full brightness
  - If no motion → LED glows dimly
